    Download
    
            
            
    
              
              
            
    
            
    Leer lassen, um den Standardordner des Spiels zu nutzen, dort wird nie etwas gelöscht. In einem eigenen Ordner löscht der Sync nach einmaliger Rückfrage alle Mods, die kein Server mit diesem Ordner braucht. Mehrere Server können denselben Ordner teilen, gemeinsame Mods werden nur einmal geladen.
    

            
    
              
    ✓ Du musst nichts weiter einstellen: „Direkt beitreten“ nutzt diesen Ordner automatisch.
    
              
    
                Nur beim Start über Steam (optional)
                
    Nur nötig, wenn du das Spiel nicht über diese App, sondern direkt über Steam startest. Trage dann diesen Text dort ein: Arma Reforger › Eigenschaften › Startoptionen. Sonst lädt das Spiel beim Beitritt alles erneut.
